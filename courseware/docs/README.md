# How Modern Programmers Think

**Course Code:** PT28604
**Duration:** Five Days
**Audience:** Professionals new to computer programming

---

## Course Description

This course provides aspiring programmers with a solid foundation in core programming concepts, system navigation, file management, and data handling. Alongside these technical skills, it also develops essential soft skills and productivity habits. Designed to build a well-rounded skill set, the program prepares learners for the demands of modern software development through hands-on practice in Windows and other operating systems. By connecting theory with real-world application, the curriculum sets the stage for further learning in areas like web development, backend programming, and data analysis.

## Prerequisites

Students must have experience working with computers, navigating the file system, and editing files.

---

## Course Structure

The courseware is organized into eight modules. Each module contains an overview file (`00-overview.md`) followed by individual topic files. The course is designed to be followed sequentially, as later modules build on concepts introduced in earlier ones.

### Progression Model

The course uses a progressive approach to code examples:

- **Modules I–III** — Conceptual foundations using plain English and pseudocode
- **Modules IV–VI** — Transitional, introducing real commands (Git, SQL) alongside pseudocode
- **Modules VII–VIII** — Real code in JavaScript and Java with full explanations

These bands describe the *primary* teaching vehicle of each phase, not a hard rule. Two deliberate exceptions appear earlier: brief, clearly-labeled *"here's the same idea in a real language"* previews (so learners can see where the pseudocode is heading), and code-*reading* exercises — reading and critiquing real code is treated as a beginner skill in its own right, distinct from writing it.

## How to Use This Courseware

Each topic file is a self-contained chapter that includes explanatory prose, real-world analogies and business parallels, examples (progressing from pseudocode to real code), and review/discussion questions. The `00-overview.md` in each module provides learning objectives and context for the topics that follow.

This courseware is designed for instructor-led delivery over five days but can also serve as a self-study reference.

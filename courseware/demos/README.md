# Instructor Demo Scripts

**How Modern Programmers Think — PT28604**

This folder contains step-by-step instructor scripts for the 38 technical demonstrations performed during the five-day course. Each script includes objectives, setup instructions, commands and code to type live, talking points, key takeaways, and anticipated student questions. Demos are scoped for an audience new to programming — most run 13–16 minutes, with foundational or setup-heavy demos (Git internals, SQL JOINs, and the Java/JavaScript toolchain) running up to 18–20 minutes and quick observational demos as short as 12.

## How to Use These Scripts

Each demo script includes:

- **Objective** — What students should understand after watching
- **Setup / Prerequisites** — What to prepare before class
- **Step-by-Step Script** — Exact commands, code, and talking points to follow live
- **Key Points to Emphasize** — The most important takeaways to reinforce
- **Common Questions** — Anticipated student questions with brief answers

These scripts are designed to be followed verbatim or adapted to your teaching style. Rehearse each demo at least once before class to ensure your environment is configured correctly and all tools are installed.

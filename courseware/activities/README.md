# Course Activities

**How Modern Programmers Think — PT28604**

These 20 activities are designed to reinforce and apply concepts from the courseware. They progress from reflective and exploratory exercises in the early modules to hands-on coding activities in the later modules, mirroring the journey from newcomer to emerging programmer.

Several activities use the course's running example, **[CivicTrack](../course-project/README.md)** — a 311-style citizen service-request system — so the week builds toward one application students come to understand end to end.

## Progression at a Glance

**Activities 1–5 — Foundations and Self-Awareness** (Modules I–II): Reflective exercises that help students understand the programming landscape and set themselves up for sustainable learning. No coding required.

**Activities 6–10 — Tools and Teamwork** (Modules III–IV): Hands-on practice with the essential tools of the trade — command line, VS Code, Git, Markdown, and code review. Students begin producing real artifacts.

**Activities 11–15 — Thinking Like a Programmer** (Modules V–VI): Structured exercises in computational thinking, data structures, algorithms, and data management. Pseudocode and paper-based design lead into SQL and data analysis.

**Activities 16–20 — Writing Real Code** (Modules VII–VIII): Students write, debug, and compare real JavaScript and Java programs, build a webpage, and culminate with a personal learning roadmap and portfolio.
